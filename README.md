# 杭州嘉惠食品有限公司网站

现有网站的 GitHub Pages 静态发布目录。`index.html` 与原项目入口逐字节一致，包含现有样式、交互、图片、425 条产品记录及原产品目录 PDF。

网站首页保留原有介绍与配图，天成蛋液与聚朗馅料展示区位于产品搜索栏上方，目录及系列筛选优先展示这两个系列，其他原料提供配套选择。公开网址：https://joey-wang-ui.github.io/-/ 。

电脑鼠标增加轻柔的跟随光晕、悬停光圈与按钮、图片光影，品牌文字逐项入场。触屏、系统减少动态效果及高对比度模式关闭光标装饰，保留正常浏览，自定义圆点和光圈显示时隐藏系统光标，输入与弹窗恢复原生光标。

## GitHub Pages

公司名称字体基于 Adobe 思源宋体 SemiBold，已内嵌首页。字符子集、来源说明和 OFL 许可保存在 `fonts/`。

品牌栏支持柔光、放大及选中高亮，点击品牌可直接筛选产品并跳到目录，支持键盘和手机操作。

仓库 Settings → Pages → Build and deployment：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

不需要前端构建、数据库或后端服务。`.nojekyll` 用于直接发布静态文件。网站内容含目录所列的业务联系电话和地址。

完整可编辑源码与备份仍保存在原工作项目中。此仓库保留实际上线所需的静态入口。
